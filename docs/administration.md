# Адміністрування

Цей розділ описує команди, доступні лише адміністраторам бота (користувачам, чиї ID прописані в коді або конфігурації як адміністратори - *примітка: на даний момент перевірка прав адміністратора може бути не реалізована жорстко, будьте обережні*).

## Приховані команди

### `/resetrankings`
**УВАГА! Ця дія незворотна.**
Повністю очищує базу даних рейтингів. Всі гравці повертаються до початкового рейтингу 1200, а таблиця лідерів очищується.
Використовуйте цю команду лише для глобального скидання сезону або при серйозних збоях.

### `/addlegend <name> <rating> [wins] [losses]`
Додає фейковий запис до таблиці лідерів (Arcade Mode). Це дозволяє "заповнити" таблицю лідерів на початку роботи бота, щоб новим гравцям було з ким "змагатися" візуально.

**Приклад:**
```bash
/addlegend "Grandmaster" 2500 100 2
/addlegend "Bot_AI" 1500 50 50
```

Ці записи матимуть спеціальні від’ємні ID, щоб не конфліктувати з реальними користувачами.
