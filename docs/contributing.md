# Contributing

Thanks for contributing! Follow these guidelines to make collaboration smooth.

Workflow

1. Fork the repo and create a feature branch with a short, descriptive name.
2. Write code and tests. Ensure tests pass locally.
3. Open a pull request against `main` with a clear description of the changes.

Coding standards

- Keep functions small and focused.
- Add tests for logic changes.
- Update docs when you change user-facing behavior.

Commit messages

- Use concise messages and reference issues when applicable.

Review

- Maintain backwards compatibility where possible.
- Respond to review comments and iterate on the PR.

Contact

- Use the repository issue tracker for discussion and proposals.
