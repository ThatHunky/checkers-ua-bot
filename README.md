# Checkers UA — Telegram бот для українських шашок

![Checkers UA Banner](checker_ua_icon.png)

Легкий PvP Telegram-бот для гри в українські шашки з підтримкою контейнерів (Podman/Docker), локалізації та збереження стану гри.

**🎮 Публічний бот:** [`@checkers_ua_bot`](https://t.me/checkers_ua_bot)

---

## 🚀 Можливості

- **Правила українських шашок**:
    - Обов'язкове взяття (биття).
    - «Літаючі» дамки (хід на будь-яку відстань).
    - Прості шашки б'ють вперед і назад.
    - Серійне взяття (мульти-джамп).
- **Matchmaking (PvP)**: Грайте з випадковими суперниками вашого рівня або запрошуйте друзів.
- **Рейтингова система (ELO)**: Змагайтеся за першість у глобальному рейтингу.
- **Історія ігор**: Переглядайте повтори своїх матчів хід за ходом.
- **Повна українська локалізація 🇺🇦**.

## ⚡ Швидкий старт (Podman/Docker)

1. **Клонуйте репозиторій та створіть `.env`**:
   ```bash
   cp .env.example .env
   # Відредагуйте .env, вкажіть ваш TOKEN від @BotFather
   ```

2. **Запустіть контейнери**:
   ```bash
   podman-compose build
   podman-compose up -d
   ```

## 🧪 Тестування

Для запуску юніт-тестів:
```bash
pip install -r requirements.txt
pytest -q
```
